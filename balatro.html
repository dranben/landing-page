Balatro RL Agent

A reinforcement-learning agent that plays full Balatro runs against the real, unmodified game engine, booted headless with no game logic reimplemented.

PythonGymnasiumMaskablePPOLuaJITBehavior cloning

The idea

Most game-playing agents train against a reimplemented or simplified copy of the game. I wanted the agent to learn against the real thing: the actual, unmodified Balatro Lua source, so the policy never overfits to a fake.

What I built

  • A harness that boots the real game headless under LuaJIT 2.1 with the visuals stripped, driven from Python. No game logic is reimplemented; the harness reads the source but never modifies it.
  • A Gymnasium environment wrapping a full run, all jokers, shop, consumables, boss blinds, vouchers, and packs, with the action layout derived from the game's own source.
  • A MaskablePPO trainer that scaled across 28 parallel workers, plus a behavior-cloning warm-start pipeline to bootstrap early policies.
  • A training dashboard (Flask + Chart.js) to watch runs live.

The hard part

The headline debugging win: a reward-shaping bug that I diagnosed and fixed, lifting the model's explained variance from −120% to +71%, the difference between a value function that was actively misleading and one that actually predicted returns.

Before any of that, the real challenge was the bridge itself: driving a commercial game engine headless and exposing its sprawling action space to an RL agent cleanly enough to mask illegal moves and decode actions back into the game.

Status

A research project I keep iterating on. It's where I do my systems-level Python and machine-learning work, equal parts emulation plumbing and RL.

The game's Lua source is commercial and not redistributed, so the repo stands alone without it. Glad to walk through the training pipeline and the reward fix.
