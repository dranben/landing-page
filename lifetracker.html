LifeTracker

A progressive web app that pulls health, productivity, and finances into a single momentum score, with an AI read on every day.

ReactViteTypeScriptHonoCloudflare WorkersD1PWAClaude APIGoogle OAuth

The problem

I was tracking my life across half a dozen apps and spreadsheets, and none of them answered the only question I actually cared about: am I trending up or down? Health, productivity, and money each lived in their own silo, so there was no single read on whether a given week was good or bad.

What I built

LifeTracker is a single installable PWA that brings those domains together behind one number: a momentum score. You log the day, and the app rolls everything into a tactical dashboard with high / medium / low momentum states, plus an AI daily analysis that reads the day's data and writes back a short, plain-language summary of what changed and why.

  • A React + Vite + TypeScript front end, built as an offline-capable PWA.
  • A serverless backend on Cloudflare Workers (Hono) that serves the app and the /api and /auth endpoints, backed by Cloudflare D1.
  • Google OAuth with a signed session cookie; the schema was designed multi-user from day one.
  • The Claude API integrated server-side to generate the automated daily insight.

Architecture

React + Vite PWA ──/api──► Worker (Hono) ──► D1 (SQLite) momentum UI auth · scoring history │ │ offline cache Claude API (daily read)

The Worker is the whole backend: it serves the built SPA as static assets and hosts the API, so there's one deploy, one origin, and no separate server to babysit.

The hard part

Two things were genuinely hard. First, designing one honest metric across noisy, unrelated domains, so that a good sleep week and a good spending week move the same needle in a way that still feels fair. Second, making the AI daily read actually worth reading: feeding it the right slice of structured data and constraining it so it summarizes the day instead of hallucinating advice.

Status

Shipped and in daily private use (currently just me and my wife). It is the most product-shaped thing I've built: real auth, a real database, a real serverless API, and an AI feature that earns its place.

Private app, so there's no public demo. Happy to walk through the code and the momentum model on a call.
