redline

An all-in-one GPU overclock, system monitor, RGB control, and stability suite. One desktop app to replace MSI Afterburner plus RivaTuner.

PythonPySide6NVAPIWindows

The problem

Tuning a GPU usually means juggling two or three separate tools: one for the overclock, one for the on-screen monitor, another for RGB. I wanted a single app that did all of it, so I built one.

What I built

  • A PySide6 desktop application with a live system monitor for clocks, temperatures, and load.
  • GPU overclock controls and an RGB control panel in the same interface.
  • A stability suite to push a configuration and watch it hold under load.
  • Direct hardware access through NVAPI, NVIDIA's low-level driver API, called from Python.

The hard part

This was a step outside the web stack and into systems work: reaching the GPU through a low-level, sparsely documented driver API, then keeping a real-time monitor responsive while the card is under stress. It's the project where I learned to talk to hardware instead of HTTP.

Status

A personal tool I run on my own machine. It replaced the Afterburner + RivaTuner combo for my day-to-day overclocking and monitoring.

Private desktop project. I can demo the running app and walk through the NVAPI layer; deeper internals on request.
