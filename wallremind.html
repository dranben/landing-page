WallRemind

Push a reminder straight to your phone's wallpaper. A small distributed system that spans a Cloudflare Worker, R2, push notifications, and a native Android app.

Cloudflare WorkerTypeScriptR2FCMKotlinAndroid

The idea

The lock screen is the one surface you always see. WallRemind turns it into a reminder channel: any client (including Claude through an MCP tool) posts some text, and a few seconds later it's the wallpaper on my phone.

How it works

  • A client POSTs reminder text to a Cloudflare Worker.
  • The Worker renders the text into a phone-resolution SVG and stores it in R2.
  • It sends a Firebase Cloud Messaging data message to the registered device.
  • The Android app (Kotlin) fetches the SVG, rasterises it, and calls WallpaperManager.setBitmap().

Architecture

+---------+ POST /reminder +------------------+ FCM data msg +--------------+ | Client | -----------------> | Cloudflare Worker| ---------------> | Android App | | (MCP) | | (SVG -> R2) | | (SVG->Bitmap)| +---------+ +------------------+ +------+-------+ | | | GET /wallpaper/<id>.svg | +----------------------------------->+ v WallpaperManager .setBitmap()

The hard part

This is the project that taught me distributed thinking: state and work are split across a serverless backend, an object store, a push channel, and a phone that's often asleep. Getting the handoff right, generate once and store, notify by reference, fetch and render on device, meant designing for a flaky last mile instead of a clean request/response.

Status

Working across the Worker and the Android client. The repo is laid out as worker/ (TypeScript), android/ (Kotlin, FCM, AndroidSVG), and an MCP server that exposes the set_wallpaper_reminder tool.

Happy to demo it live, sending a reminder and watching it land on the lock screen, or walk the code.
