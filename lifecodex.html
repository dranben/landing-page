Full-stack · Editor · MCP

LifeCodex

A self-hosted Notion: pages, freeform databases, and saved views, with a hand-rolled editor and a remote connector that lets an AI read and write the whole workspace.

React 19ViteTypeScriptHonoD1R2KVGoogle OAuthMCP

The problem

I wanted Notion's shape, pages, databases, and views, without renting it, and without locking my own notes inside someone else's product. So I built a single-user, cloud-first knowledge base I fully own, where the canonical store is plain Markdown and JSON so an export is always trivial.

What I built

  • A tree of pages (Markdown documents) and databases (a JSON schema), with entries (rows), saved views, and a revisions trail.
  • A React 19 + Vite + TypeScript front end served by a Cloudflare Worker (Hono), backed by D1 for data, R2 for backups, and KV for tokens.
  • Google OAuth with a signed, revocable session, single-user by design.
  • A remote MCP connector exposing roughly a dozen tools, so Claude can do full CRUD over pages and entries plus search, schema changes, history, and restore.
  • Durability without a second master copy: nightly R2 snapshots plus an on-demand full-JSON export.

The hard part

Two pieces carried the project.

The editor is hand-rolled on native contentEditable, with zero editor dependencies, no ProseMirror, no BlockNote. The canonical logic is a pair of pure functions, parse and serialize, with a round-trip unit test proving serialize(parse(x)) === x stays stable. That test is what makes the editor safe to keep extending.

The MCP connector is Streamable-HTTP JSON-RPC with full OAuth 2.1 + PKCE and dynamic client registration, KV-backed tokens, and identity tied to the Codex session so only the allowlisted user can authorize. Every AI edit, delete, or schema change snapshots the prior row into revisions first, and deletes are soft, so the AI can never quietly destroy anything.

Status

Built and self-hosted on Cloudflare. It's a personal workspace, so there's no public login, but it's the deepest single thing I've built: a custom editor, a real auth layer, an AI integration with a safety net, and a backup story across two independent homes.
